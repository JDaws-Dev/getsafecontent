**What SafeTube Does:**

SafeTube allows parents to create a curated, ad-free YouTube experience for their children. Parents:
- Search and approve specific videos/channels using the YouTube Data API
- Create kid profiles with individual content libraries
- Monitor watch history
- Set time limits

Kids can only watch parent-approved content - they cannot browse or search YouTube directly.

**API Usage:**

We use the YouTube Data API v3 for:
- `search.list` - Parents search for videos/channels to approve
- `videos.list` - Get video metadata for approved content
- `channels.list` - Get channel metadata

We do NOT:
- Allow kids to search YouTube directly
- Display YouTube recommendations or ads
- Modify or upload any content
